## Design Context

### Users

Builders across Northern Ireland's public-service ecosystem use this repository when they need to move from a strategy opportunity to informed exploration quickly. They are likely to clone the project and work with a coding agent. The interface must help them understand the opportunity, inspect the published research and synthetic working data, load the matching domain build partner, and recognise the limits before choosing what—if anything—to build.

### Brand Personality

Editorial, industrial, energetic. The experience should feel confident, candid, and useful: an independent open-source field manual assembled for working builders, not an official government service, generic AI product, showcase, or dashboard.

### Aesthetic Direction

Use a light, tactile annotated-field-manual direction with asymmetric composition, oversized editorial type, hard structural rules, large indexes, margin notes, source fragments, dataset cells, repository paths, and command-line artefacts. The palette is paper, peat, ultramarine, acid green, and signal orange. Avoid generic card walls, stock AI imagery, glass effects, decorative gradients and shadows, dark-mode theatre, or government-service imitation. The memorable signature is a connected trail from opportunity to source to starter data to repository skill.

### Design Principles

1. Accelerate understanding, not conclusions: present multiple possibilities and never imply a recommended application.
2. Make provenance structural: real published sources, synthetic working data, interpretation, and unknowns must remain visibly distinct.
3. Turn repository artefacts into the interface: paths, commands, fields, and annotations are working material, not decoration.
4. Use dramatic hierarchy with disciplined restraint: one strong focal moment, sharp scale contrast, asymmetric rhythm, and very few conventional cards.
5. Accessibility is part of the visual system: WCAG 2.2 AA, keyboard operation, visible focus, reduced motion, forced colours, and 200% zoom are release requirements.
